# ダメージ計算ルール

出典: League of Legends Wiki（公式）/ 리그오브레전드 인벤 / 톡피지지

---

## 基本のダメージ軽減式 ✅

```
実ダメージ = 元ダメージ × 100 / (100 + 実効防御力)
```

目安: 防御力100で被ダメ半減、200で1/3。

---

## 貫通・減少の適用順序 ✅

**必ずこの順で計算する。順序を間違えると結果が変わる。**

1. 固定防御力減少（デバフ。例: ブラッククリーバー）
2. 割合防御力減少（デバフ）
3. **割合防御貫通**（アイテム。例: ドミニク卿）
4. **固定防御貫通**（脅威 / Lethality）← 最後

```
実効防御力 = 防御力 × (1 - 割合貫通) - 脅威
```

用語の区別:
- **減少(reduction)** = 敵のステータス自体を削る
- **貫通(penetration)** = 貫通分を「無いもの」として計算する（ステータス自体は減らない）

固定防御力減少は防御力を0未満まで下げられるが、割合減少は0未満にできない。

### 計算例（脅威18・相手防御力100）
```
実効防御力 = 100 - 18 = 82
倍率 = 100 / 182 ≈ 54.95%   （脅威なしなら50%）
```

### 計算例（割合貫通30% + 脅威18・相手防御力100）
```
① 100 × (1 - 0.30) = 70    ← 割合が先
② 70 - 18 = 52             ← 固定が後
③ 倍率 = 100 / 152 ≈ 65.8%
```
※順序を逆にすると (100-18)×0.7 = 57.4 になり誤答する。

---

## 割合貫通は乗算で合成される ✅

```
合計貫通率 = 1 - (1 - a) × (1 - b) × ...
```
例: 10%が2つ → 1 - (0.9 × 0.9) = **19%**（20%ではない）

## ダメージタイプ別の軽減 ✅

| タイプ | 防御力・魔法防御の影響 |
|---|---|
| 物理 / 魔法 | 通常通り軽減される |
| **固定（トゥルー）ダメージ** | 防御力・魔法防御を完全無視。**スキル/アイテムによる軽減効果も無視** |
| **割合(HP%)ダメージ** | 「防御力無視」ではない。HP%で数値を出した後、**通常通り防御力軽減が適用される** |

固定ダメージの例外:
- ダメージ増幅系アイテムは固定ダメージにも乗る
- 係数がAD/APに紐づく固定ダメージは、そのステータスを削られると数値も下がる

## クリティカル ✅

- **基礎クリティカルダメージ倍率 = 200%**（パッチ26.01で175%から復帰）
  - ⚠️ 古い攻略記事の「175%」表記は現パッチでは誤り
- インフィニティエッジで **+30%** → 合計230%（⚠️ +35%表記のソースもあり、要検証）
- クリ率50% + 基礎倍率 = 平均ダメージは実質150%相当
- クリ発生は独立試行ではなく、外れが続くと次の発生率が上がる仕組み（KR資料）

## 脅威は「乗数」、ADは「母数」 ✅

```
最終ダメージ = (基礎ダメージ + AD) × 100/(100 + 防御力 - 脅威)
```

- **AD1点の価値** = 常に一定
- **脅威1点の価値** = 今持っているダメージ量に比例して変動する

→ 序盤にADが少ないうちに脅威だけ積んでも絶対量は伸びない。
**ADで母数を育ててから脅威を乗せる**のが定石の理由。

（「脅威は序盤しか意味がない」は半分正しい：*貫通効率*は序盤が高いが、
*絶対的な価値*はAD母数が育った後の方が大きい。この2つは別の話。）
